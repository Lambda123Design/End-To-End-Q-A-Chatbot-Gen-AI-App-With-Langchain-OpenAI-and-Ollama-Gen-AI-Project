# End-To-End-Q-A-Chatbot-Gen-AI-App-With-Langchain-OpenAI-and-Ollama-Gen-AI-Project
This Repository contains my working files of "End To End Q&amp;A Chatbot GEN AI App With Langchain, OpenAI and Ollama Project", an Gen AI Project

(i) Implemented an end-to-end Q&A chatbot using OpenAI models like GPT-4 and GPT-4 Turbo, as well as open-source models like LLama and Mistral. 

(ii) Developed a Streamlit web app where users can enter questions, select models, and adjust settings like temperature and max tokens. 

(iii) Integrated LangChain to manage LLM interactions and LangSmith to track queries, responses, and usage. 

(iv) Demonstrated real-time responses with monitoring of metadata like token usage and latency. 

(v) Set up the project structure, environment variables, and requirements for a complete end-to-end workflow.
